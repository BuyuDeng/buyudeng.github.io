# Buyu Deng — Academic Website

Personal academic website for Buyu Deng, hosted with GitHub Pages at
[buyudeng.github.io](https://buyudeng.github.io/).

## Structure

- `index.html` — content and page structure
- `css/styles.css` — visual design and responsive layout
- `assets/img/` — portrait and favicon

## Preview locally

From the project directory, run:

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000`.

## Publish

After reviewing the changes:

```bash
git add .
git commit -m "Redesign academic website"
git push origin main
```

GitHub Pages will publish the updated `main` branch.
