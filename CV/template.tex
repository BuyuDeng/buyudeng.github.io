\cvproject{CO$_2$ Storage Modeling and Rock Physics Agent Development}
\cvlist{
  \item Compared five vertical grid resolutions (0.04--0.92 ft) in ECLIPSE 300 CO$_2$STORE simulations using fixed-time plume geometry, fixed-location saturation histories, space-time plume metrics, and computational cost; selected 0.12 ft for subsequent modeling.
  \item Built a facies-based rock physics workflow using mineral averaging, Hertz--Mindlin dry frames, Wood fluid mixing, and Gassmann substitution to map geology and CO$_2$ saturation to elastic properties.
  \item Generated baseline and time-lapse seismic responses for 20 years of CO$_2$ injection and 80 years after shut-in; interpreted horizon-relative amplitude slices in Petrel.
  \item Designed an agent workflow around the Stanford Rock Physics and Borehole Geophysics (SRB) model library exposed through Model Context Protocol (MCP) tools for model discovery, input validation, and traceable calculations.
  \item Conducted 45 independent agent runs across Smeaheia, glass-bead, and White patchy-saturation benchmarks under three resource settings: no references, textbook guidance only, and textbook guidance plus SRB tools.
  \item Without references, agents made unsupported model assumptions; textbook guidance matched reference calculations. SRB MCP tools enabled direct model calls and matched the references when used correctly, but some runs misinterpreted tool outputs and produced incorrect predictions.
}
Presentation: \cvlink{https://buyudeng.github.io/Final_Presentation.pdf}{\underline{Final slides (PDF)}}\par\vspace{0.3em}

\cvproject{Geo-VAE for 3D Geophysical Data Compression and Latent Processing}
\cvlist{
  \item Adapted Wan-VAE with cached causal pseudo-temporal resampling along the crossline axis, achieving isotropic 8$\times$8$\times$8 downsampling and 31.0:1 scalar compression for 256$^3$ cubes.
  \item Demonstrated strong reconstruction fidelity across five 3D geophysical modalities while achieving a favorable balance of GPU memory use and inference time among tested state-of-the-art video VAEs on 128$^3$--512$^3$ cubes.
  \item Built a unified compact latent space for RGT-conditioned seismic generation and complete-volume 768$^3$ denoising, enabling condition-responsive generation and scalable field-volume processing.
}
